# Xuan-Hien Le — Academic Website

A lightweight, single-page academic website designed for GitHub Pages.

## Files
- `index.html` — all page content
- `styles.css` — visual design and responsive layout
- `script.js` — mobile menu and automatic copyright year

## Recommended GitHub Pages deployment
1. Open this repository in GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and `/ (root)`.
5. Save.
6. The site should become available at `https://hienlx88.github.io`.

## Before publishing widely
Review the biography, timeline, selected publications, and profile photo. Add an institutional email to the Contact section if desired.
